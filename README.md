# Haunted Harvest

Haunted Harvest is a CSS-only interactive Halloween experience created using HTML5 and CSS3.

## Features
- Three interactive Halloween scenes
- CSS-only scene navigation using :target
- Animated ghosts, bats, fog, clouds, vehicles, and characters
- Responsive layout for desktop and mobile
- Halloween color palette using CSS variables
- Keyboard focus styles
- Reduced-motion accessibility support
- No JavaScript

## Scenes
1. Haunted House
2. Haunted Graveyard
3. Midnight Pumpkin Festival

## Technologies
- HTML5
- CSS3
- Flexbox
- CSS animations
- CSS variables
- CSS pseudo-classes
